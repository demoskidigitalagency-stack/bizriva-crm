# Automations

Workflow grammar:
Trigger → Condition → Action → Wait → Branch → Goal.

## Trigger groups
Contact, Lead, Conversation, Form, Order, Payment, Delivery, Inventory, Marketing, Time.

## V1 actions
Create/update contact, create lead, assign/reassign, move stage, add/remove tag, segment membership, create task, send WhatsApp/email/SMS, notify team, create draft order, reserve inventory, update field, webhook, wait and branch.

Every execution must be observable in logs. Failed executions must not disappear silently.
