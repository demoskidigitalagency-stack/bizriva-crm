Send every form entry and WooCommerce order to your Bizriva CRM — one install, no webhook per form.

== Description ==
Catches Contact Form 7, WPForms, Gravity Forms, Elementor Pro forms, Fluent Forms and WooCommerce orders and sends them to Bizriva, where they become contacts, leads and orders you can follow up on WhatsApp.

== Installation ==
1. Plugins → Add New → Upload Plugin, choose bizriva.zip, Activate.
2. In Bizriva: Website & Forms → Add a connection → Custom website. Copy the address and secret key.
3. In WordPress: Settings → Bizriva, paste both, Save, then Send a test.
